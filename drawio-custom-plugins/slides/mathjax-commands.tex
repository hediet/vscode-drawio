% The commands of LaTeX packages that the MathJax of draw.io lacks, each defined from what MathJax
% has.  \fatsemi is the fat semicolon of stmaryrd, which Unicode writes as Z notation schema
% composition, and \mathds is the double-struck alphabet of dsfont.
%
% The VS Code extension yujunhuang.drawio-slides gives these lines to math-definitions.plugin.js,
% and the build of the draw.io presentation framework writes the ones a page uses into the page.
% Each line other than a comment is one \def of one command.
\def\fatsemi{\mathbin{\unicode{x2A1F}}}
\def\mathds{\mathbb}
